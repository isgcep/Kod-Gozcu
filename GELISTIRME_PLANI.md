# KodGözcü – Geliştirme Planı

Bu çalışma yalnızca `Kod-Gozcu-Gelistirme` dalında yapılır. `main` dalı ve mevcut `index.html` dosyası korunur.

## Hedefler

1. Mevcut kod inceleme ekranını bozmadan geliştirmek.
2. Kod ve değişiklikleri daha anlaşılır Türkçe incelemek.
3. URL girilerek web sayfasını analiz edebilen bir yardımcı eklemek.
4. Kullanıcı onaylamadan sayfada hiçbir işlem yapmamak.
5. Groq API anahtarını güvenli sunucu tarafına taşımak.
6. Chrome uzantısı dosyalarını ayrı bir klasörde hazırlamak.

## Güvenli çalışma sırası

- Her yeni özellik ayrı dosyada hazırlanır.
- Önce geliştirme dalında test edilir.
- Mevcut `index.html` dosyası korunur.
- API anahtarı ve parolalar GitHub'a eklenmez.
- Web yardımcısı ilk aşamada yalnızca analiz yapar.
- Kullanıcı onayı olmadan tıklama veya form gönderme yapılmaz.

## İlk aşama

Önce mevcut dosyalar ve klasörler incelenir. Ardından bağımsız yeni dosyalar eklenir.
