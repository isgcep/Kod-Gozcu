🚀 Hızlı Başlangıç

KodGözcü'yü kendi GitHub reponda çalıştır. Her PR'da otomatik kod incelemesi al.

1

Groq API Key Al

console.groq.com'a git → Üye ol → API Keys → Create Key. Key'i kopyala.

2

GitHub Secret Ekle

Repo → Settings → Secrets and variables → Actions → New repository secret
Name: GROQ_API_KEY | Value: Groq'tan aldığın key

3

Workflow Dosyası Oluştur

Repo'da yeni dosya oluştur: .github/workflows/kodgozcu.yml
"Workflow" sekmesinden hazır YAML'i kopyala, yapıştır, commit et.

4

PR Aç ve Test Et

Yeni branch oluştur → dosya değiştir → Pull Request aç.
30 saniye içinde AI yorumu PR'a eklenir! 🎉

💡 İpuçları

  • Ücretsiz: GitHub Actions (2000 dk/ay) + Groq ücretsiz tier
  • Model değiştir: llama-3.3-70b-versatile veya deepseek-r1-distill-llama-70b
  • Sadece belirli dosyalara bakmak için paths: filtresi ekle
  • Prompt'u özelleştirerek farklı inceleme kriterleri belirle
  • Türkçe yorumlar için prompt Türkçe yazılmış, değiştirmene gerek yok

🔍 Kod Diff İncele

Diff kodunu yapıştır, AI anında incelesin. API key girmezsen demo modunda çalışır.
